GroupedStatistics

Return compact chart data computed on the host's DuckDB connection.

  • __init__(self, connection: DuckDBPyConnection)
  • boxplot(self, groups: list[int], values: list[float | None], *, outlier_limit: int=0) → list[BoxSummary]

    Use continuous quartiles, observed Tukey whiskers, and bounded outlier samples.

  • boxplot_html(self, groups: list[int], values: list[float | None], *, title: str, outlier_limit: int=0) → str

    Render the precomputed boxes as a Plotly trace.

  • top_categories(self, categories: list[int | None], values: list[float | None], labels: dict[int, str], *, limit: int) → list[CategoryTotal]

    Aggregate by stable ID and preserve distinct missing and remainder totals.

  • degree_distribution(self, vertices: list[int], edges: list[tuple[int, int, int]]) → list[DegreeCount]

    Count weighted directed degrees with one incoming and outgoing contribution per loop.

  • weighted_means(self, groups: list[int], values: list[float | None], weights: list[float]) → list[WeightedMean]

    Keep the numerator and valid weight for each group for later rollups.

  • combine_weighted_means(self, groups: list[WeightedMean], parents: dict[int, int]) → list[WeightedMean]

    Roll up summaries using only their two stored aggregate components.

  • error_bars(self, groups: list[int], values: list[float | None], *, method: ErrorBarMethod) → list[ErrorBar]

    Calculate sample variance and an interval around each group mean.
