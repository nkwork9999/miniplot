Miniplot

DuckDBの集計をグラフ、HTMLレポート、画像出力につなぐ可視化拡張。

INSTALL miniplot FROM community;
LOAD miniplot;
SELECT pie_chart_html(['A', 'B'], [1.0, 2.0], 'Shares');

機能ガイド

チャートの種類と軸基本チャート、時間軸、3D、ヒートマップ、WebGLの利用例を掲載しています。レポートと出力JSONのレポート仕様、HTML、PNGとPDFの出力方法を説明します。集約と前処理時系列縮約、欠損による区間分割、ヒストグラムの利用方法を掲載しています。性能と検証条件データサイズ、シリアライズ、出力の計測条件と結果を確認できます。
